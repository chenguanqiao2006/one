# 代序 让读者自己创造奇迹——黑马王子访谈录
> 来源：书页码 1–5，《证券市场红周刊》记者 余郑 访谈。
### 【核心定义】
- **"涨停密码"不神秘**：王子以公安开锁为喻——"拿三根不同形状的铁丝，什么样的锁具都能打开"。本书运用《伏击涨停》"四大定律"，从"涨停基因"入手，总结基因合成密码的科学规律。
- **基因与密码**："涨停基因"是单个的，"涨停密码"是组合的。"基因"一词来自希腊语，意为"生"，是遗传物质最小功能单位。股票也有生、长、病、老、死；**强庄做的股票必强、精庄做的必精、狡庄做的必狡**，都会在基因或基因组合中表现出来。
### 【市场机理】
- **十月怀胎、一朝分娩**：庄家运作股票好比"十月怀胎"，涨停或走牛就是"一朝分娩"。一旦"怀胎"到"分娩"关头，大盘猛跌它要涨停、大盘狂跌它还是要涨停——因为不涨停，"十月怀胎"的股票可能就要出大问题。
- **涨停后能否延续也看基因**：涨停一下又复旧下跌，是"怀胎"有问题、孩子不健康；涨停接着涨停，是"怀胎"健康、有营养。
### 【实战要点】
- **案例·万向钱潮（2014）**：王子 2014.1.29（I 柱）盘前预报，密码由 3 组基因构成：①F、G 两小倍阳形成"接力双阳"，上攻基础已成；②H 到 I 两组连续"倍量伸缩"，动能齐备；③H 柱倍量攻击左峰 D 柱、可能"回踩凹峰"，跳板找到。预报后第三、四天连获两个涨停板。J 柱含"零号基因"，密码是"**零号不补，后市如虎**"，此后连续 3 个一字板，休整一天后又涨停。
- **理念是灵魂、技术是躯壳**：所有涨停基因必须符合"三先规律"原理，所有密码必须符合规律的组合；脱离三先规律，技术就是无源之水、无本之木。
- **核心只有 8 个字**："**量价阴阳、真假虚实**。"
- **熊市牛股共性**：把熊市牛股图形缩小看整体，共性是"价格越涨、成交量越小"——"价升量缩，后市必火"。
### 【现代化升级】⭐ 8 个字就是本项目的立项书
1. **"量价阴阳、真假虚实"**——前四个字是量学的原纲领，**后四个字正是本项目账本每天在干的事**。2014 年王子把"真假虚实"写进量学核心八字，但受限于当时的数据手段只能靠人眼感悟；2026 年我们用 cv/corr/tail_ratio/flatness 四票把它变成每只股票每天的自动判定。**这不是巧合，是量学自己预留的接口，本项目是它的完成形态。**
2. **"零号不补，后市如虎"参数化**：零号基因=跳空丁字板（缺口未回补）。判定：`跳空当日 gap>2%` AND `后续 N 日 low > 跳空日前收盘`（缺口不补）→ 强势确认。补了→密码损坏。
3. **"强庄必强、精庄必精、狡庄必狡"的量化**（与《伏击涨停》第 9 章庄性量化联动）：30 日窗口 is_real 占比+回踩秩序 → 庄性自动分档。**"看懂密码就是看懂庄家"的 2026 版：庄家人格=is_real 统计特征。**
4. **万向钱潮密码的三组基因结构**（接力双阳+倍量伸缩+回踩凹峰）就是基因扫描器的输出格式模板：**密码=带时间戳的基因序列，每个基因带 is_real 标签。**

# 前言 从"涨停基因"到"涨停密码"
> 来源：书页码 5–9。
### 【核心定义】
- 每根量柱都是一种"基因"，可"助涨"也可"助跌"；"涨停基因"=专门有助涨停的基因。
- 单个"助涨基因"只含"涨停因子"、并非一定促使涨停；几个助涨基因组合形成"涨停密码"，不但可促使涨停，还可能涨停接着再涨停。
### 【市场机理】——基因与密码的转化规律
1. 基因是单个的、孤立的，密码是多个的、连锁的；本书重在研究多基因组合的密码。
2. 单个基因有助涨助跌双重功能，多个基因排列组合成一定密码才有助涨可能。
3. 密码由量柱和价柱特殊形态组合而成："接力双阳"=两个小倍阳；"极阴次阳"="极阴"+"次阳"；"倍量伸缩"=一系列"倍量伸长"+"倍量缩小"。
4. **特殊情况下，一根量柱和其价柱的组合也能构成很好的密码**："跳空丁字板"既是基因也是密码，可衍生"零号不补，后市如虎"。
5. **基因和密码可以被损坏**：受损顺序"**自右向左、各个击破**"，一旦损坏助涨功能丧失、助跌功能产生；随后新的助涨基因又"**自左向右、逐个生成**"——周而复始，形成"量价阴阳、真假虚实"的循环转换与动态平衡。
6. **基因和密码都带庄家性格**：强庄做的必强、精庄做的必精、狡庄做的必狡。
### 【实战要点】
- **案例·佛塑科技（2014）三阶段**：A~B 两小倍阳组成"接力双阳"+百日低量群（基础打好）；C~E"跳空""过左峰"形成"跳空过左峰"超级密码，D、E 两组倍量伸缩清洗浮筹；F~H"极阴"+"次阳"组成"极阴次阳盖阴+涨停突破左峰"密码。预报后隔一日涨停，I 柱暗藏"缩量涨停"密码，其后进入主升浪。
- 本书 18 种密码只是沧海一粟，更多基因密码有待读者挖掘总结。
### 【现代化升级】⭐ 基因损坏的状态机模型（本册最重要的理论升级）
原书第 5 条"自右向左损坏、自左向右生成"是一条完整的**状态机描述**，直接可编码：
class 涨停密码状态机:
    # 生成期（自左向右逐个点亮）
    基因点亮顺序 = [g1, g2, g3, ...]  # 按时间从左到右
    状态 = 点亮数量 / 总数
    # 损坏期（自右向左逐个熄灭）
    损坏判定:
        g最新失效 → 撤一个基因 → 密码降级
        全部失效 → 密码死亡，转入新的孕育期
    生命周期: 孕育(点亮中) → 分娩(全亮+触发) → 衰退(右端熄灭) → 死亡 → 新孕育
**工程意义**：
1. **密码强度可量化**：点亮基因数/总基因数 = 怀胎进度条（0-100%）；
2. **损坏预警**：最右端基因失效（如"跳空不补"变成"跳空补了"）= **第一个撤退信号**——比价格破位早；
3. **循环监控**：死亡密码的原壳体上重新点亮新基因 → 新密码候选（原书"周而复始"的工程化）。

# 第 1 章 十月怀胎 一朝分娩
### 【核心定义】
- 任何涨停板、任何牛股都不是天上掉下来的，而是庄家或主力精心策划、长期运作的杰作。
- 比喻：庄家运作股票好比"十月怀胎"，涨停或拉升好比"一朝分娩"；女人分娩不管"行情"（打雷下雨要生、地震海啸也要生）；主力"分娩"也不管行情——大盘折腾它要涨停、大盘暴跌它也要涨停。
- **"涨停密码"**：构成股票涨停或走牛的基本因子组合，可以是单个基因（如倍量柱），也可以是组合基因（如倍量伸缩）。
### 【市场机理】
**看量柱三层次（国兴地产，图 1-2）**：
1. **看全貌**：以 O 点为中线，左侧两组"百日低量群"、O 点附近又一组，共三组
2. **看性质**：左侧两组对应走势松散、无攻击力；O 柱右侧第三组里悄悄潜伏 A~F 六根有价值量柱，其中竟有**四个"卧底矮将军"**
3. **看组合**：A、B 与 D、E 之间有三组"倍量伸缩"——"倍量拉升"后紧跟"倍量收缩"
**三条怀胎机理**：
- 一旦出现（或重复出现）长时间"百日低量群"，即可能进入"十月怀胎"；特别是**"价柱波浪滔天"而"量柱风平浪静"**的结构要重点关注
- 短时间内王牌柱密集，可能进入"一朝分娩"前夜
- 连续、密集的"倍量伸缩"可能就是"涨停临盆异动"；本书许多案例在倍量伸缩后第 2、3、5、8 日出现涨停
**看量线九条看点（国兴地产）**：
- O 点右侧每个突出低点都自然切合左边关键点位，形成底部逐级抬高的 **8 条精准线**，量柱不温不火、主力谨小慎微
- **看 O 线**：历时 **8 个月**，三处探底精准重合仅差 1 分钱
- **看 R 线**：也历时 8 个月，三处凹间峰精准冲击 R 线，触线即回落、毫不恋战、主动回撤
- **四组长阴短柱洗盘**：每次回踩精准线即上攻，控盘稳健
- **P、Q、R 三处精准回踩平衡线形成精准十字架**：洗盘突然、拉升也突然
- **8.30（C 柱）、8.31 连续两根"假阴真阳"**、9.8 又是一根：凡"假象"都是"异动"，"假动作"后必有"真意图"
- **最精彩的战斗在虚实双衡精准线的交替攻防中**："实则虚之、虚则实之，兵来将挡、水来土掩"
- 8 个涨停基因在两周内密集呈现、越往后越密集=一朝分娩前奏。**掌握"虚实相生"两条线，是精明主力操盘绝招**
### 【实战要点】
1. **案例·英唐智控（图 1-1，2014.1.17 留影）**：创业板**亏损股，市盈率为零、市净率高达 5.2 倍**，传统眼光没有上升空间。但从 D 柱（2013.12.30）至 2014.1.18 共 14 个交易日，大盘跌 115 点，它却先后拉出 **4 个涨停板、涨幅 46.60%**。

# 第 2 章 凹口淘金 一抓就灵
### 【核心定义】
- 窍门：打虎要打腰、杀猪要捅喉；股市伏击涨停最好的窍门就是"找凹口"。任意股票"凹口"数不胜数，但值得伏击的"凹门"不多——一旦找到，就找到了一只装钱的口袋。
- **凹口淘金三要素**：
  1. **凹口要突然凹陷**：突然凹陷的必须是**长阴短柱基因**（主力挖坑标志）；没有这个标志的凹陷是主力出逃的凹陷，何时进去都是陪葬品
  2. **凹线要顺其自然**："凹线"=凹口平衡线，最可靠画法="**以下跌最凶狠的大阴实底画水平线**"（自然画法）；人工画法不提倡
  3. **凹底要刹车换挡**：凹底一定要有**两个将军柱**——第一个扭转跌势（刹车）、第二个转为升势（换挡）；**越近越有爆发力**；第二个将军柱出现才确认淘金
### 【市场机理】——三步动作（山西三维，图 2-1）
1. **凹口长阴短柱**：凹口 C 柱是形成凹口时最长的阴价柱，对应却不起眼的阴量柱，其后所有阴量柱都矮于 C 柱=长阴短柱是洗盘
2. **凹底刹车换挡**：D、E 几乎同一水平线——
   - **D 柱是"隐形黄金柱"（元帅柱）**：藏得深，躲在高量阳柱右侧、比左侧阴柱只高一点点，但其后三日价升量缩、是典型黄金柱，扭转 C 柱以来跌势（**刹车**）
   - **E 柱是跳空小倍阳**：后三日价升量缩，也是黄金柱；E 左侧一阴一阳两根价柱最低点都没破 D 柱黄金线（阴柱 **9.50 元**精准持平、阳柱 **9.51 元**上浮 1 分钱），E 自身小倍阳盖过左侧双阴（**换挡**）
3. **凹底加油飙涨**：E 柱后第四天最低点刚好踩 E 柱黄金线，第五天 F 柱向上跳空、刚好骑在"凹口平衡线"上奋力拉升，与 C 柱完美对称
### 【实战要点】
1. **预报背景**：王子 2010.12.20 发布"凹门淘金"涨停趋势预报，截至 12.24 五个交易日涨停榜上大都是凹口淘金股；大盘跳空下跌、满眼皆绿时两市仅两只涨停——"山西三维"和"深鸿基"。
2. **口诀**："**D 刹车，E 换挡，F 加油就飙涨。**"
3. **案例·深鸿基（图 2-2，2010.12.24）**：按法则"以杀跌最凶狠的大阴实底画平衡线"，A 柱实底就是凹口平衡线；B 柱"矮将军"出现=刹车；B 柱后第三天 C 柱**三倍量刺破凹口平衡线（换挡）**，此后连续 8 个交易日"踩着凹口平衡线"运行=**现场直憋**（加油），终于在趋势预报第五日冲冠一怒封涨停。
4. **凹底纪律**：没出现两个将军柱之前、或只出现第一个时，暂时不能列入"凹口淘金"；第二个将军柱出现才确认。
5. **案例·有研硅股（图 2-3，真假之辨）**：乍看很像典型凹口淘金，但前两只都涨停、唯独它不涨停。三要素检验：
   - **看 F 柱**：是本轮下跌"最凶狠的长阴"，但**不是长阴短柱**——对应量柱很高大、超过前面所有阳柱；不是长阴短柱的股票上攻后劲不足
   - **以 F 柱实底画线**：**不符合凹口平衡线标准**
   - **凹底是否两个隐形将军**：D 柱虽是矮将军，但右侧接力的 E 柱是**六倍高量柱**、上攻凶猛不含蓄——拉升太张扬、透支上攻动能
   - 前两只贵在"**得其道、得其神**"，有研硅股差在"**得其技、忘其神**"
6. **论坛学员精华（178448.com，原样保留）**：
   - **林京海（12 楼）**：①左侧必是大阴柱且必是长阴短柱；②凹坑底部将军柱"个不高、不起眼、隐藏"，后续可能出现第二个将军柱构成接力；③平衡线以大阴柱底部画线，精准点位越多越好
   - **杨阳阳（13 楼）**：第一个隐形将军刹车、第二个隐形将军换挡，两将军完成接力（加油）才是关键密码
   - **安华跃（34 楼）**：长阴说明凹口突然坍塌；短柱说明主力没大量卖出筹码——右侧底部能出现隐藏接力将军柱，才形成密码
   - **金鹰（61 楼）**：凹口淘金一般跌破 20 日均线，底部需将军柱扭转 20 日线；长期低量柱后重新拉起，各均线绞合、成本趋同，恰在凹口平衡线附近，一根大阳才有产生条件
### 【现代化升级】
1. **三要素全参数化**：
长阴短柱: 阶段最大实体阴线 AND 量比 < 0.5 AND 有底（low≈前关键位±0.5%）  # 2026 补丁：排除被动赎回

换挡: 换挡柱阳盖阴 + 底部不破刹车柱黄金线（±0.5%）

2. **有研硅股反例=机器特征的古典识别**：E 柱"六倍高量柱、上攻凶猛不含蓄"——**"含蓄"的量化定义=倍量不超过 3 倍（与《伏击涨停》第 16 章"伸倍量要含蓄"同源）**；六倍张扬在 2026 年还要加一道：is_real 检查（对倒刷出的六倍量更不能碰）。原书 2014 年就在防"张扬"，与我们的"放量≠进场"完全同向。
3. **金鹰学员的均线观察**（20 日线/5 日 10 日绞合）是量学与均线体系难得的兼容案例——均线绞合=**成本趋同**，本质是筹码分布指标，可以保留为辅助过滤器。

# 第 3 章 卧底将军 凹底淘金
### 【核心定义】
- "凹口淘金"重在"凹口"，舍弃了"凹底"至"凹口"之间的利润（有的高达 30%~50%）；**"凹底淘金"**要求在"凹底"启动第一时间加入主力队伍。
- **发现主力卧底三要素**：①股价处于阶段性凹底（长阴短柱、百日低量群）；②有凹底精准谷底线或平量柱；③凹底附近藏有凹底矮将军（最好形成底部小黄金柱）。
- **"凹底矮将军"（W 底矮将军）**：处于波段底部的、个头小的、不起眼的"王牌柱"；具备涨停基因的矮将军有"双重特性"：一是"不起眼"，二是"将军柱"。
### 【市场机理】
- 2011 年春节后首个交易日（2.9）受央行加息影响大盘低开 20 点、收"阴锤头"，两市 15 只涨停、其中 12 只属"凹底矮将军"起涨；次日 18 只涨停、16 只属矮将军；第三日 19 只涨停、16 只属"矮将军黄金柱"——**矮将军大面积涨停，因为主力操盘手法更隐蔽，矮将军就是见证**。用矮将军出征可"示人以弱"。
- **具备涨停密码矮将军三条件**：
  1. **基础要扎实**：矮将军一般诞生在"长阴短柱"组成的、长期缩无可缩的低量群之后；东光微电在整整 **40 天**百日低量群中诞生，许多涨停股都是缩量横盘 30 天左右
  2. **基因要共振**：至少 2~3 个涨停基因组合才能生成密码
  3. **阳柱要盖阴**："单阳盖阴"=某根阳价柱盖过左侧第一阴价柱；"双阳盖阴"=连续两根阳价柱盖过

1. **案例·东光微电（图 3-1）**：次新股，从 **35.40 元**跌到 **20.65 元**、跌幅 **38.56%**；除上市最初 8 天外几乎都是长阴短柱下跌、长期缩无可缩的休眠状态。低量柱中一根悄悄突起的 A 柱温和起步、其后三日价升量缩=凹底矮将军。
   - 以 A 柱次日实底 **21.85 元**画水平线 C（A 柱黄金线），A 柱后回调都不破 C——**只要回踩不破黄金线，就有异军突起可能**
   - B 柱比 C 线高 1 分钱开盘、于 **21.86 元**起跳，小倍阳一举突破左峰平台、完成"双向胜阴"，次日跳空高走封死涨停
2. **《量柱擒涨停》第 5 讲**："山不在高，有仙则名；柱不在高，含金则立。"将军柱不在"高大粗红"，而在能否"独当一面"、能否"支撑走势"。

### 【核心定义】

- **股市含义**：特指价柱悄悄集结在某条重要攻防线（平衡线）下方，给人上不去的虚弱假象；对手放松警惕或条件成熟时，股价一鼓作气冲过攻防线。
### 【市场机理】——试关冲关三规律（浙江东日，图 4-1）
三道防线：
- **①号线**（左侧大阴实顶平衡线）：下方 A、B 两矮将军挂帅，一串小阳柱集结，两个小倍阳上引线侦察①号线压力、欲过不过，次日即冲过
- **②号线**（实顶凹间峰平衡线）：阴影框内都是兵员集结区，多次用长上引线侦察，长达 **22 天**兵临城下后 C 柱倍量上攻回落、两天缩倍量上攻又回落，但每天都触及②号线，次日 D 柱顺利过关
- **③号线**（虚顶凹间峰平衡线）：D 柱最高点精准测试③号线后逐日回落、踩②号线集结，E、F 两矮将军接力过③号线又回落，对手放松警惕时 G 柱小倍阳轻松过关
**试关冲关三规律**：
1. 每轮攻关前，总有"**上引线**"充当"侦察兵"试探防线压力
2. 每轮攻关中，总有**两个矮将军前后配合、左右夹击**
3. 每轮攻关后，总有**回踩攻防线**动作，站稳了即再次向上攻击
**卧底碎阳矮将军**：一串零碎小阳，第一个小阳 A 不起眼但"倍阳过阴"；连续两根平量柱+一根小倍阳柱，价位大幅提高而量柱没变化（"价升量缩"），量柱 A 升格为黄金柱。**有将军柱卧底的凹底才值得关注。**
