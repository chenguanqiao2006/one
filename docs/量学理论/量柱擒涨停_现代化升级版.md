# 第一单元 · 基础原理（第1–6讲）
## 第1讲 量柱的「三重序化」/ 第4版改「三重特性」
### 【核心定义】
量柱是「**股市温度计**」：能将无序走势有序化、零散 K 线系统化、庄家操盘思路节律化。
### 【三大功能】
| 功能 | 内容 |
|------|------|
| ① 序化盘面结构 | 将无序的走势有序化 |
| ② 细化波段节奏 | 将未来的走势节律化 |
| ③ 量化走势幅度 | 将未知的走势度量化 |
### 【现代化升级】
第 4 版（2021）将本讲「三重序化」改为「**三重特性**」，表述为量柱的**全息性、孪生（衍生）性**：
- **全息性**：量柱浓缩全部市场信息
- **孪生/衍生性**：量柱与价柱孪生、可衍生出黄金线/黄金梯等
- [部分细节原著待查]
**再现代化（2026）**：全息性在量化时代必须加限定——**量柱全息，但量柱可被伪造**。「全息」的前提是「真实」，这正是本项目「真假量柱账本」存在的意义：先用 1 分钟微观结构判定真伪，再谈全息。

### 【核心定义·三大规律】
| 规律 | 别称 |
|------|------|
| ① 卖在买先 | 卖买平衡律 |
| ② 价在量先 | 价量平衡律 |
| ③ 庄在散先 | 庄家导向律 |
### 【三级预报】
阻力预报、撑力预报、涨停预报。
### 【现代化升级】
三先规律是量学的公理层，2026 年依然成立，但**「庄在散先」的主体必须改写**：
| 原书 | 2026 现实 |
|---|---|
| 「庄家」=单一实体，通过量柱看穿其意图 | 「庄」=机构+量化算法集群，同一只票几十个算法同时运作；散户贡献 86% 成交量，是被建模和收割的对象 |
「卖在买先」「价在量先」作为**市场机制**的描述不变；「庄在散先」作为**博弈主体**的描述必须升级为「**算法在散先**」。

2. 量柱是「有性」的实体

## 第4讲 量柱的形态和品质
### 【核心定义】
- **本质**：量柱是成交量的真实记录。
- **形态（六种量形）**：倍量柱、高量柱、低量柱、平量柱、缩量柱、梯量柱。
- **品质**：量柱在特定位置表现出的性质高低。
### 【现代化升级】六量形参数化扫描表
这是全书最核心的现代化产出之一。六量形全部可参数化识别，可直接写入 `liangxue_genes.py`：
| 量形 | 原书定义 | 2026 参数化定义（可直接编码） |
|---|---|---|
| 倍量柱 | 比前日量 ≥2 倍，红柱，容差 10% | `vol >= ref(vol,1) * 2 * (1 ± 0.10)`（保守）/ `*1.75`（激进）；`is_real == true` 才有效 |
| 高量柱 | 某阶段最高量柱 | **市值分桶后桶内分位数**：`vol_rank_in_bucket >= 0.90` |
| 低量柱 | 某阶段最低量柱 | 同上：`vol_rank_in_bucket <= 0.10` |
| 平量柱 | 相邻两柱高度差 ≤3% | 并肩：`abs(vol/ref(vol,1)-1) <= 0.03`；凹口放宽至 0.05 |
| 梯量柱 | 连续 3 根以上逐步升高 | `vol[i] > vol[i-1] > vol[i-2]` 连续 N≥3 |
| 缩量柱 | 比前日相对缩小 | `vol[i] < vol[i-1]`；缩倍柱 `vol[i] <= vol[i-1] * 0.5` |
**「品质」的现代化定义**：位置（拐点）× 真伪（is_real）× 量级（分位数）三者的乘积，不再是「看图感觉」。

## 第5讲 「量级」的确认和划分
### 【核心定义】
「量级」不看量柱高矮红绿，而看它在多空博弈中占据的**战略地位**。
> 「将军柱」不在于其「高低红绿」，而在于其能「独当一面」，在于其能否「支撑走势」。
**三个层次**：
| 层次 | 内容 |
|------|------|
| 量形（形） | 倍量、高量、缩量、平量、梯量、低量六种 |
| 量性（性） | 试探、建仓、增仓、补仓、震仓、启动、拉升、将军、黄金柱九种 |
| 量级（级） | 最重要的「将军柱」和「黄金柱」 |
**比喻**：普通量柱=士兵；将军柱=将军（独当一面、支撑走势）；黄金柱=大将军（主力精心打造的核心支点、市场动能焦点）。
### 【市场机理】
**一、确认将军柱——三大原则**
| 原则 | 标准 | 含义 |
|------|------|------|
| ① 三日不破 | 量柱后三日最低价未跌破此柱最低价 | 「不破位」才能独当一面 |
| ② 价升量缩 | 后三日有「价升量缩的缩量柱」支撑 | 即「黄金柱」=大将军，是确认量级的**最佳量柱** |
| ③ 先者优先 | 连续几根都合格，以第一根为准 | 第一根才是「第一推力」 |
实践中符合三原则的**多数是倍量柱、少数是高量柱**，其他量柱仅在特定阶段才可能充当将军柱。
以**莱茵生物**为例：图中 A、B、C、D、E、F、G、H、I、J、K 共 **11 根**量柱都是倍量柱，其后三天走势都向上——倍量柱是确认量级的「首选量柱」，高量柱是「次选量柱」。
**二、划分攻防线——三步**
1. **以将军柱为基准**：十字线对准该柱，核对量级标准，用箭头标注
2. **以「后三日最低价」为参照**：
   - 后三日最低价均在实体上方 → 以实体**上沿**画平衡线
   - 有一天在实体下方 → 以实体**下沿**画平衡线
   - 最简画法：直接以后三日最低价位置画平行线
3. **以「缺口顶」为补充**：将军柱若跳空高开，以柱下方「缺口顶部」画平行线
这条平行线就是「攻防线」：攻到这里会停、跌破就危险。
**三、预测目标位**
- **海螺水泥（600585）**：确认「栋梁之柱」后可见明显的 **7 级台阶**
- **主庄**=主导股票走势的庄家=拼搏中的「赢家」，也称「赢庄」
**实战案例**：
- 海螺水泥=高量柱+二日价升量缩=**准黄金柱**，涨停在望
- 莱茵生物=高量柱+三日价升量缩=**真黄金柱**，必有涨停
- 【2009.7.3 验证】莱茵生物预报日（2009.4.29）最低价 **15.50 元**，连拉 4 波共 **14 个涨停**，最高达 **39.75 元**
### 【实战要点】
1. **找将军柱**：十字线逐柱对比，后三日不破最低价、最好价升量缩者即是
2. **画攻防线**：将军柱后三日最低价处画水平线；线上持有、跌破警惕
3. **倍量柱优先**：优先关注倍量柱，高量柱次选
4. **缺口顶补充**：跳空高开的将军柱，攻防线画在缺口顶部
5. **不臆断、看对比**：品质不能只看高低，要从相邻量柱「力量」对比判断「力道」倾向
### 【现代化升级】
1. **术语**：第 4 版「将军柱」归入「**王牌柱**」大类。判定三原则不变。
2. **倍量柱优先的前提**：**is_real == true**。2026 年回测显示放量突破 20 日新高的倍量柱次日胜率 45.59%，**跑输基准 2.48 个百分点**——「倍量柱=首选」的结论只对真量柱成立，对倒出来的假倍量柱反而是诱多信号。
3. **攻防线的现代化画法**：将军柱后三日最低价仍是基准，但**必须加市值分桶校验**——大盘股的攻防线用「实体上沿/下沿」更可靠（波动小），小盘股的攻防线必须用「后三日最低价」宽松画法（波动大，严格画法天天破线）。
4. **目标位预测**：7 级台阶式预测在 2026 年仅适用于大盘蓝筹/趋势股；连板/题材股的连板高度从 2020 年 4.5 板压到 2025 年 2.3 板，台阶预测必须砍半。

## 第6讲 「量性」的转化和升华
### 【核心定义】
「量性」=量柱的性质。低量/高量/倍量是**形状**，支撑柱/将军柱/黄金柱是**性质**。量性是量柱在**特殊位置（空间）、特殊时段（时间）、特殊性能（积极/消极）**的集合。离开量性单看量柱，会陷入「形而上学的泥潭」——这是单凭量柱判断失误的根本原因。
- **积极量性=乘法效果**：原有量性的**升华**
- **消极量性=除法效果**：原有量性的**退化**
### 【市场机理】
**一、时间转化——三日定性**（「一个篱笆三个桩，一个好汉三个帮」，量性退化/升华主要由后三日决定）
| 序号 | 后三日形态 | 量性变化 |
|------|-----------|---------|
| (1) | 价升量缩、逐步走强 | 升华，获「黄金柱」身价（控盘趋稳、卖盘枯竭、将拉升） |
| (2) | 先阴后阳、先衰后强 | 改头换面、官升一级（先洗后启、假摔真拉） |
| (3) | 阴阳相间、有气无力 | 量性退化、面临调整（多空分歧、犹豫不决） |
| (4) | 实体缩小、先强后弱 | 力量衰退、面临调整（动能衰竭、可能出货） |
**福星股份（图1-6-1）A–G**：
| 柱 | 形态 | 结论 |
|----|------|------|
| A | 倍量柱，第三日又倍量 | 黄金柱 |
| B | 倍量柱，先强后弱、第三日巨阴 | 次黄金柱 |
| C | 小高量柱，先弱后强 | 准黄金柱 |
| D | 高量柱，价升量缩 | 真黄金柱 |
| E | 最明显高量柱，阳后双阴、量价齐落 | 次黄金柱，遭 **18 天**调整 |
| F | 不起眼平量柱，价升量平 | 黄金柱 |
| G | 身兼倍量+高量，收敛三角形 | 将向上突破 |
**二、空间转化——拐点定性（四个关键拐点）**
| 拐点 | 说明 | 案例 |
|------|------|------|
| ① 平台起柱 | 整理平台突然出量柱 | 红阳能源平台倍量柱→横盘 5 天逆市涨停 |
| ② 凹口起柱 | 回调成凹口时竖中到大阳 | 天目药业凹口倍量柱→连续涨停 |
| ③ 过顶起柱 | 冲过左侧平行峰顶时出中到大阳 | 大连金牛 A 柱、B 柱、A1 柱 |
| ④ 触底起柱 | 触前期峰底时出中到大阳 | — |
四种拐点上的量柱一般具「将军柱」性质、可当栋梁；不在拐点的量柱性能多弱化。
**三、组合转化——集合定性（三种关键量群）**
1. **低量柱+倍量柱**：A 柱（4.2）、C 柱（1.23）前都是阶段低量柱、自身却是倍量柱。机理：主庄「**休克疗法**」探底后心中有数的主动拉升，后势必大涨。
2. **倍量柱+倍量柱**：长力股份 3.25、3.26；天目药业 5.13、5.14。机理：多出现在阶段底部，是主庄控盘好、急于拉升的体现；但「**物极必反**」，连续三根倍量柱最好持币观望。
3. **缩倍柱+倍量柱**（缩倍柱=比前日缩量一倍以上）：
   - 通宝能源 5.12 缩量一倍→次日起连续上涨几乎不回头
   - 靖远煤电 4.30 缩量一倍→次日连续拉升，区间涨幅 **222%**
   - 三峡水利 5.11、5.12 连续缩量一倍→5.20 大盘大跌却逆市涨停
   - 机理：突然缩量一倍如屏住呼吸，主力「坐山观火、放任自流」，机会一到即大幅拉升
### 【实战要点】
1. **三日定性是金律**：倍量/高量柱先看后三日，价升量缩=升华、量价齐落=退化
2. **拐点位置最关键**：平台/凹口/过顶/触底四位置的倍量柱才有将军柱价值，半山腰的可能是诱多
3. **低量+倍量=休克底部**：地量后再倍量，完成「探底—确认—启动」三部曲，最可靠底部之一
4. **连续三根倍量柱要警惕**：物极必反，不宜仓促介入
5. **量群分析是核心**：单柱是形而上学，量群才是辩证法
6. **量性可转化**：今天的高量柱可能是明天的将军柱也可能是出货柱，关键看后三日与位置
### 【现代化升级】
1. **三日定性算法化**：后三日价升量缩=「后三日收盘价逐日递增 且 量能逐日递减」→ `close[i+1]>close[i]` 且 `vol[i+1]<vol[i]`（i=后三日）；可写入 `liangxue_genes.py`。
2. **缩倍柱+倍量柱的组合是 2026 年回测中表现最强的形态**：极致缩量（量比 ≤0.3）次日胜率 +3.07%，配合后续倍量确认——这条在量化时代依然有效，因为**缩量难以伪造**（对倒做量容易，做缩量难）。
3. **倍量+倍量的警告升级**：2026 年连续倍量柱更要警惕——两根倍量中只要有一根是 `is_real: false`，就是算法在诱多对倒，不要等第三根了，直接拉黑。
4. **拐点定性的位置判定**：平台/凹口/过顶/触底的识别本身要用日线数据算（阶段高点/低点识别），配合分位数更准。

# 第二单元 · 六个元素（第7–12讲）
## 第7讲 倍量柱：实力与雄心的温度计
### 【核心定义】
按「前推法」，倍量柱=**比前一日量柱增量一倍或一倍以上的红色量柱**。三特征：
1. 必须与前一日量柱相比
2. 增高一倍或以上（容许 **10%** 误差）
3. 必须是红柱/阳柱（高开低走的「假阴柱」也视为阳柱），因倍量柱伴随的股价一般上涨
**三大特性（广博股份案例）**：
1. 当天几乎都是「绝对底部」或「相对底部」
2. 当天几乎都是走势的「拐点」或「起点」
3. 后面都有一波不错的「上升走势」或「盘升走势」
### 【市场机理】
1. **实力介入的标志**：庄家有本事让量增高、没本事让量缩小；敢增量一倍=故意宣告「我来了、有实力接住所有抛盘」
2. **主力抢筹的标志**：底部「倍量拉升」不是为解放散户，而是「倍量抢筹」
3. **一箭多星**：主力赚钱必经「试探、建仓、增仓、补仓、震仓、启动、拉升、出货」八环节，成倍拉升一个动作同时兼容八项功能
4. **性质复杂**：
   - 主动行为：建仓柱、增仓柱、补仓柱
   - 被动行为：试探柱、震仓柱、护仓柱
   - 盘势发展：黄金柱、启动柱、拉升柱
**广博股份（图2-7-2）逐柱**：
| 柱 | 性质 | 说明 |
|----|------|------|
| A | 试探柱 | 横盘 8 天后突然发力，试盘见抛盘轻、连续拉升 |
| B | 建仓柱 | 调整 8 天、将跌到 A 次日倍量柱顶部时建仓 |
| C | 增仓/护仓柱 | 调整 6 天跌到 B 次日倍量柱顶部，突然倍量拉升 |
| D | 补仓柱 | 站上 5 日均线放量上攻、抛压不重 |
| E | 黄金柱（非倍量） | 大拉大洗、最凶一天跌 10%，但未破 E 最低价 |
| F | 启动柱 | 突破 5 日均线后拉升 |
| G | 被动吸筹 | 倍量兼高量、遇阻成倒锤头小阳 |
G 柱前都是一个庄家操盘；G 遇阻说明 2008 年被套主力或已开始出套，可能形成多主力拼搏局面。
### 【实战要点】
1. **倍量当天是介入最好时机**：尤其相对低位或重要量柱平衡线处
2. **倍量柱平衡线是最好防守线**：主力很少打乱阵脚，稍有跌穿也会很快拉回（多主力控盘股有例外）
3. **判准性质是踏准节奏的扶手**：能看出操作目的，就能跟随主力意图与节奏
**维维股份（600300，图2-7-3，2009.4.13 截图）**：
- 预测第一目标位 **13.30 元**、第二目标位 **18 元**
- A–G 七柱，除 G 外 6 根都是倍量柱：
  - A：三天小阳盘升后突然拉升，大试大吸
  - B：试探到一年下跌已无多少抛盘，大胆建仓
  - C：BC 间平稳、增仓明显，稳扎稳打
  - D：走势如 ABC、有补仓迹象
  - E：倍量兼次黄金柱，连续三个大幅拉升后震仓
  - F：借震仓平台突破前高、稳健拉升（**预报点、测幅基准**）
  - G：非倍量，是高量柱/阻力位
- **核心思维**：站在主力角度看势做势，不要老以散户思维追涨杀跌
> 口诀（原著精神提炼）：倍量柱，红柱看，比前日量翻一番；低位倍量是抢筹，高位倍量要防范；当日介入是机会，平衡线处是防线；结合三日定量性，价升量缩才升华。
### 【现代化升级】⭐ 本讲是全书升级密度最高的地方
1. **容差参数校准**：
   - 保守口径：`vol >= ref(vol,1) * 2 * (1 ± 0.10)`（原书）
   - 激进口径（2026 同花顺主流公式）：`vol >= ref(vol,1) * 1.75`
   - 建议系统同时输出两个版本，11-01 体检时用沙盘数据选优
2. **「实力介入」的方向性警告（最重要）**：
   原书机理「庄家有本事让量增高」隐含**「放量=主动行为」**的假设。**2026 年回测反例**：
   - 放量突破 20 日新高：次日上涨率 **45.59%**（基准 48.07%，**-2.48 个百分点**）
   - 放量中阳：次日 **41.41%**（**-6.66 个百分点**）
   - 天量长上影：次日 **37.31%**（**-10.76 个百分点**）
   
   **结论**：在量化时代，「放量」可能是**算法诱多**而非主力介入。倍量柱的效力判定必须加 `is_real` 过滤。
3. **倍量柱效力判定树（v2.0 新增，可编码）**：
   IF isreal == false:      标记「机器倍量柱」→ 诱多警告，非买点
   ELIF isreal == null:     标记「疑似倍量柱」→ 观察，不入信号池
   ELIF 位置 in (平台/凹口/过顶/触底) AND 换手率分位 in 合理区间:
                             标记「有效倍量柱」→ 进入量学基因池
   ELSE:                     标记「普通倍量柱」→ 仅作参考
4. **「假阴柱也视为阳柱」的补充**：原书这条在 2026 年要加警惕——高开低走+放量+收阴的组合，在量化时代高频出现在「假突破出货」里，判定时必须看 `is_real` 和后续 3 日不回落验证。

## 第8讲 高量柱：欲望与走向的温度计
### 【核心定义】
高量柱=某一阶段最高的量柱，最容易发现、最容易激动、也最容易让人上当。
- 「介入标志说」与「退却标志说」两种截然相反的观点**都是错误的形而上学**
- **三种正确做法**：
| 类型 | 特征 | 操作 |
|------|------|------|
| 巨量出货的「发烧柱」（A柱） | 连续两根「超级倍量柱」递增 | **避之** |
| 无量涨停的「启动柱」（B柱） | 连续两根「温和梯量柱」递增 | **擒之** |
| 价涨量减的「黄金柱」（E柱） | 价升量缩、量价背离 | **察之** |
### 【市场机理】
**生成原理（三先规律）**：
1. **卖在买先**：有人大量卖、同时大量买，必是大资金大庄家杰作
2. **价在量先**：卖方与买方欲望达到双向平衡的高峰才产生高量柱
3. **庄在散先**：庄家某种欲望预谋得到市场共鸣；欲望制造者藏在幕后、以假象示人
**三种识别与预判**：
- **发烧柱**：A、C 柱连续两根超级倍量柱递增，把买卖欲望推向极高潮，**狂热掩护出货**，务必避之
- **启动柱**：B、E 柱连续两根温和梯量柱递增，「温和」里藏狂热、次日价升量缩暗示拉升
- **黄金柱**：价升量缩、控盘程度最高
**「我们需要的高量柱——三个条件」**：
1. 必须是某阶段**局部**最高量柱（如 B，甚至很不起眼）
2. 可以但不一定是全局最高量柱
3. 后量柱必须逐步走低、对应价位必须逐步走高（B、E 皆然）
> 用三条件衡量，只有 **B、D、E** 合格；标记时 A、C、F 应过滤。
**「高量黄金柱」特征**：高量柱后三根量柱逐步缩小、三根 K 线逐步升高，呈量价背离；沿 K 线上升画线、沿量柱下降画线=张开的「**喇叭口**」。
### 【实战要点】
1. **不要一刀切**：先分发烧/启动/黄金三类型
2. **发烧柱要避**：超级倍量递增常是疯狂掩护出货
3. **启动柱可擒**：温和梯量递增、后价升量缩暗示拉升
4. **黄金柱要察**：控盘最稳、最值得研究
5. **三条件筛选**：阶段局部最高、不一定全局最高、后量走低价位走高
6. **画喇叭口**：张开的喇叭口=高量黄金柱典型特征
7. **结合后三日**：高量柱本身不能判涨跌，价升量缩=升华、量价齐落=退化
**验证案例**：
- **中银绒业（000982）**：F 柱后缩量一倍以上→次日阴十字星、第三日涨停回落收 **9 点**大阳，一周涨近 **20%**
- **凌云股份（600480）**：**4.54 元**（起步）→ **11.35 元**（4.10）
- **同达创业（600647）**：**7.85 元**→ **13.13 元**（4.2）
- **中兵光电（600435）**：**9.65 元**→ **22.90 元**（4.7）
### 【现代化升级】
1. **「某阶段最高」必须市值分桶**：原书「阶段最高」没有市值概念。2026 年必须按流通市值分桶取桶内分位数（top 10%），否则大盘股永远测不出高量、小盘股天天「高量」。
2. **发烧柱 vs 假发烧**：原书「发烧柱=两根超级倍量递增」是出货信号，这条在 2026 年被强化验证（天量长上影次日胜率 37.31%，比基准低 10.76 个百分点）。**但反向也成立**：对倒刷出来的「超级倍量」如果 `is_real: false`，就不一定是「狂热出货」，可能是量化在测试流动性——**先看真伪再定性**。
3. **高量黄金柱的「喇叭口」可参数化**：后 3 根量柱递减 + 后 3 根收盘价递增 → `vol[i+1]<vol[i]` 且 `close[i+1]>close[i]`（i=后三日）。

## 第9讲 缩量柱：价位与人气的温度计
### 【核心定义】
缩量柱=比此前量柱相对缩小的量柱，主要三种：
| 类型 | 特征 | 后市倾向 | 操作 |
|------|------|---------|------|
| 第一类 | 连续量缩价跌、量价同步向下 | 跌到极限后否极泰来 | 最后一根阴柱被阳柱覆盖时介入 |
| 第二类 | 连续阴阳不齐、量柱参差 | 暗示调整在即 | 第一根量柱开盘价设攻防线 |
| 第三类 | 连续价升量缩、量价背离向上 | 过顶触底做多 | **最有价值**，择机介入、防打劫 |
- **缩倍柱**=比前日缩量一倍以上的特殊缩量柱；「缩量一倍的缩量柱」是市场拐点出现的重要标志。
### 【市场机理】
1. **第一类·量缩价跌或否极泰来**：由 3–13 根量柱组成，产生阶段最低量柱后必然回头；应在最后一根阴柱被阳柱覆盖时介入
2. **第二类·阴阳不齐暗示调整**：A、B、E、F 柱后三日阴阳参差，都遇调整、但都在第一根量柱开盘价左右反身向上
3. **第三类·价升量缩、过顶触底做多**：C、D 柱后连续三阳、逐日价升量缩，调整不破 C/D 最低价
**最有价值缩量柱——三特点**：
1. 必须紧靠「倍量柱」或「高量柱」
2. 必须「价升量缩」，缩量越大越好
3. 可能是三根左右量柱群、逐步缩量最好，三日内收盘价须保持在第一量柱最低价上方
**中华企业（600675，图2-9-1，2009.4.10 截图）**：2009.2.10 盘前预报后两个月涨近 **50%**。
- A、D、E 为高量柱，B、C、F 为倍量柱，六柱后均缩量：
| 柱 | 后三日 | 性质 | 含义 |
|----|--------|------|------|
| A | 两阴一阳、连续缩量一倍 | 试探柱 | 严重惜售、主力买不到只好抬价 |
| B | 两阳一阴、价涨量缩不破底 | 建仓柱 | 已现惜售、向上心切 |
| C | 连续三阳、价涨量涨 | 增仓柱（梯量） | 真金白银堆起来、拉高补仓 |
| D | 三阳、价高量缩 | 黄金柱 | 惜售+拉高决心，回调不破 D 底 |
| E | 阳阴阳、量始终低、价始终高 | 高量柱 | 「价涨量高、价跌量低」，有上涨需要 |
| F | 阳阳阴、量缩价高 | 价升量缩 | 不满意当时价位、强烈上涨愿望 |
- **预测**：F 柱后「先双阳后一阴、三日左右调整」，调整不破 F 最高价 **10.71 元**
- 【2009.5.4 验证】从 **10.76 元**升到 **13.65 元**，调整最低 **11.01 元**（未破 10.71），两个涨停
- **测幅**：D 柱最低 7.20 元→双倍第一目标 15.00 元（按最高 7.50×2）；F 柱最低 9.55 元→第二目标 **19.10 元**（9.55×2）
- 【2009.6.29】冲高 **15.88 元**、收 15.25；7.15 已达 **20.80 元**
### 【实战要点】
- **核心在「确认趋势」而非伏击涨停**：有价值的缩量柱即使日后调整也不破第一量柱最低价
- **价升量缩缩量柱三大意义**：①市场惜售（卖在买先）②价格上扬前兆（价在量先）③庄散共鸣暗示（庄在散先）
1. **价跌量缩是拐点标志**：阶段低量柱次日出现红柱/倍量柱即介入好时机
2. **缩量一倍是拐点标志**：如中银绒业 F 柱后缩量一倍给了预报底气
3. **是倍量/高量柱的伴侣**：确认其升华黄金柱后可介入，但防「打劫」
> 口诀：缩量柱，看背离，价升量缩最珍贵；紧靠倍量或高量，三日不破最低价；价跌量缩是拐点，低量次日红柱来；缩倍柱后藏机会，主力静默待爆发。
### 【现代化升级】
1. **本讲是 2026 年回测中量学最强阵地**：
   - 首板涨停（缩量）次日胜率 **58.32%**（比基准高 **+10.25 个百分点**）
   - 极致缩量（量比 ≤0.3）次日 **51.14%**（+3.07 个百分点）
   - **方向确认**：缩量=惜售的核心逻辑在量化时代依然成立，因为**缩量难以伪造**——对倒可以做量，做不了缩量。
2. **「量比」字段建议入账**：`量比 = 当日成交量 / 前 5 日平均`。原书用「缩量一倍」的相对比较，2026 年标准化为量比更通用。
3. **价升量缩的参数化定义**：`close[i+1] > close[i]` 且 `vol[i+1] < vol[i]`（i=后三日），配合 `量比 < 0.7` 加强。
4. **「紧靠倍量柱或高量柱」的现代化**：相邻倍量柱必须 `is_real == true` 才有效——**假倍量+真缩量的组合在 2026 年是算法对倒的典型痕迹**（先假量抬高、后自然缩量）。

## 第10讲 梯量柱：谋攻与谋逃的温度计
### 【核心定义】
梯量柱与缩量柱对立，特征=**至少由三个量柱组合、像台阶一样逐步走高**。
### 【市场机理】
**华天科技（002185）**：图中 8 组梯量柱 A–H，两种相反走势——
- A、B、E、G、H 五组**每况愈下**
- C、D、F 三组**每况愈上**
秘密在**量价关系**。
1. **顺边走势（多数，走向衰竭）**：「步步登高」由三重原因叠加——卖盘逐步加大（卖在买先）、价格逐步抬高（价在量先）、主力逐步增仓（庄在散先）；市场抛压与多方接盘同步增加的「顺边」必走向衰竭。
   - 操作：与庄同步，「**高点逢阴即出**」
2. **背离走势（少数，走向兴旺）**：梯量形成之初，股价上升、持股者惜筹、持币者抢筹，量回落而价上升=买盘旺盛、卖盘短缺的「价量背离」；是主动吸筹，形成「梯量柱+缩量柱」的 A 量群。
   - 操作：C/D 柱后量都更低、价都更高，**第一个缩量柱出现时即擒住**
**涨停契机**：梯量柱自身涨停契机不多，但拼搏后必形成多空力量平衡点。
**达安基因（002030，图2-10-2，2009.6.30 截图）三波预报**：
1. **第一波（A柱）**：A 前 4 天步步登高、A 后 7 天步步回落、再连续 3 天平量；最低收盘价未破 A 最低价=平衡点，次日（5.12）预报后连拉 **5 个涨停**
2. **第二波（B柱）**：5 涨停后连续 5 天放量打压、7 天调整，最低收盘价与 B 平行；最后两平量柱次日（6.12）预报，开盘价与 B 最高价持平，连拉 3 个涨停，**12.50→19.80 元**、6 天涨 **58%**
3. **第三波（C柱）**：再 7 天调整，最低收盘价不破 C 底；6.30 第三次预报，早盘涨停两度打开、14:16 封死；按 B 最低 12 元计，有冲击 **24 元**的计划实力
**庄家三大习性**：①以逐步拉升的梯量柱测多空平衡点；②以逐步打压的缩量柱测最高量柱撑力；③以突然出手的爆发势实施拉升/打压
> 核心理念：用梯量柱最高点观察多空平衡点，平衡点处必有涨停、即使没有也有可观涨幅。**选股就是选庄家、买股就是买庄家**。
### 【实战要点】
| 类型 | 量价 | 操作 |
|------|------|------|
| 顺边（谋逃） | 量增价涨 | 高点逢阴即出 |
| 背离（谋攻） | 量缩价涨 | 第一缩量是买点 |
> 口诀：梯量柱，像台阶，三种量柱往上排；量增价涨是顺边，逢高有阴要出来；量缩价涨是背离，第一缩量是买点；梯量高点画防线，不破平衡是涨停。
### 【现代化升级】
1. **「选庄就是选庄家」的现代化**：2026 年「庄」=机构+量化算法集群，没有单一「庄家」可跟。梯量柱的判读价值不变，但**「跟庄」改为「跟真量流」**——梯量柱中每根都要过 `is_real`，有假即整组降级。
2. **梯量柱的参数化**：连续 N≥3 根 `vol[i] > vol[i-1]`；背离版加 `close[i] > close[i-1]` 且「梯量末段量缩」。
3. **达安基因式平衡点**：最低收盘价与 B 平行的判定在 2026 年可用 `abs(close_low - ref(close_low, n)) / ref(close_low, n) < 0.01`（1% 容差）参数化。

## 第11讲 平量柱：蓄势与爆发的温度计
### 【核心定义】
平量柱是量柱中的「**稀有金属**」：至少由两根高度相对持平的量柱组成（十字线对准相邻两柱、**高度差 3% 以内**），非常少、非常珍贵。
- 空间上：低位平量柱 / 高位平量柱
- 形态上：
| 形态 | 特征 | 后市 |
|------|------|------|
| 并肩平量柱 | 二至四根高度基本一致的量柱并列 | 温和上升 |
| 凹口平量柱 | 左右两根持平量柱夹三至四根更低量柱成凹口 | **猛烈飙升**、幅度递增 |
### 【市场机理】
平量柱绝非简单巧合，而是主力计划性与市场随机性在某时段某价位的「**天然共鸣**」，是平衡与倾斜的临界点=**蓄势与爆发的临界点**。
**三层含义**：
1. **价在量先**：平量相当于缩量，是当前价位得不到卖方支持、未来价位有调高可能
2. **卖在买先**：平量相当于惜筹，卖方力量减弱、买方暗中蓄势
3. **庄在散先**：主力按计划规定操盘手在某价位进出多少，出现平量即知双方力道平衡点；平衡是暂时的，**突破就在眼前**
**凹口平量柱的「狡猾」**：主力用「休克疗法」让市场自然运行，量缩价平；再比照之前量能稍加分力，形成左右两平量柱呵护小量柱的凹口；价位大幅提高、所用筹码资金却比梯量拉升便宜许多。
### 【实战要点】
**四维控股（600145，图2-11-1，2009.7.1 截图，6.4 盘前预报）**：A–G 七标记。
- A、B、C、D、E 为并肩平量柱、后市温和上升
- F、G 为凹口平量柱、后市猛烈飙升且幅度递增
- 验证：14 天内主力两次用凹口平量柱蓄势后一路飙升，**5.68→8.72 元**、涨 **53%**，含 1 个涨停、5 个涨停回落长阳
**涨停预报两种**：①直接涨停预报（紧靠平量柱的涨停）；②间接涨停预报（邻近一天或数天内涨停）
**渝开发（000514，图2-11-2，学员「雪狼」6.5 预报）**：A–G 七组平量柱：
| 柱 | 涨停方式 |
|----|---------|
| A | 三日平量后次日涨停 |
| B | 两个两日平量后次日涨停 |
| C | 两日平量直接涨停 |
| D | 两日平量直接涨停 |
| E | 七天凹口平量后次日涨停 |
| F | 两个两日平量次日涨停 |
| G | 两日平量后次日涨停、隔一日再涨停 |
> 口诀：平量柱，稀有金属，两根柱齐高最珍贵；并肩平量温和涨，凹口平量猛拉升；量平价涨是惜筹，量平价跌是蓄势；平衡破时爆发来，三日不跌画防线。
### 【现代化升级】
1. **参数放宽**：并肩平量维持 3% 容差；**凹口平量放宽至 5%**（2026 年同花顺公式主流口径）——凹口本身有 3-4 根低量柱的干扰，严格 3% 容差会漏掉大量凹口形态。
2. **平量柱参数化**：并肩=`abs(vol[i]/vol[i-1] - 1) <= 0.03`（连续 N≥2）；凹口=左右两柱满足并肩 + 中间 3-4 根 `vol < left_vol * 0.6` 且 `vol < right_vol * 0.6` + 间隔 ≤ 8 日。
3. **稀有金属的稀缺性在量化时代下降**：算法可以在特定价位制造「平量」以诱发散户跟风（特别是尾盘 30 分钟）——**平量柱判定必须绑定 is_real**，假平量+真拉升反而是诱多。

## 第12讲 低量柱：底线与底气的温度计
### 【核心定义】
低量柱易被忽视，但预测价值令所有量柱望尘莫及。普遍规律：**任何阶段只要形成低量柱，后面走势一定上升**，甚至不看 K 线、只看低量柱就能发现「起死回生的转折点」。
**三大特殊功能**：
| 功能 | 含义 |
|------|------|
| 停战柱 | 测试阶段性底部 |
| 支撑柱 | 测试攻防线撑力 |
| 反攻柱 | 测试临界点时空 |
**底线与底气**：
- **底线**：低量柱对应价位是庄家成本区底线
- **底气**：低量柱后出现倍量柱=底部确认且有拉升动力；无倍量配合只能确认「底部」、未必有「底气」
### 【市场机理】
**休克疗法**：让股票自然回落、到极限后自然回升。低量时卖方弹尽粮绝、买方惜筹，市场如真空，主力轻拉即涨。
**国阳新能（600343，图2-12-3，6.24 预报）**：**25.30→47.66 元**（7.23），整一个月涨 **88.37%**。A–G 七标志各对应低量柱：
| 柱 | 特征 | 黄金柱 |
|----|------|--------|
| A | 低量 | 第三日 |
| B | 价与 A 持平、量低于 A | 第二日（休克挤出 AB 间全部筹码） |
| C | 低量 | 第六日（冲过 AB 峰顶、上一台阶） |
| D | 低量 | 第三日（与左峰持平、过顶黄金柱、第三台阶铁底） |
| E | 低量 | 第二日（与左峰、右底持平，一线撑三拐点） |
| F | 低量 | 次日即倍量黄金柱（6.24 预报、当日涨停） |
| G | 低量 | 次日涨停确认 |
**三大机制**：①休克机制（测抛压）②收集机制（低量是培育黄金柱的土壤）③测幅机制（暗示成本底线）
**双重黄金柱测幅**：B 后黄金柱是对 A 后自救、D 对 C、F 对 E；两两相对黄金柱形成的黄金线=温度计刻度。
- 方法：按「台阶底线双倍」预测台阶顶部——**二测四、三测六、四测八**
- 第三级底线 **19.31 元**→第六级应 38.62，实际第六级底线 37.99（误差 0.016%）
- 第四级底线 **24.02 元**→第八级应 48.04，截稿（7.22）已到 47.66（误差 0.007%）
**底部确认**：低量柱必须是某阶段最低量柱、后走势回升，一般出现在缩量柱最后；「百日低量」可理解为长期下跌后的阶段最低量柱。
### 【实战要点】
**莱茵生物（002166，图12，4.29 预报）**：A–G 七低量柱。
- A、B：低量+次日倍量、三日筑黄金柱
- C：两个月悄悄吸筹后「坚决休克」、未破 B 平行线，探明底部次日以**五倍量**拉第一个涨停、再连拉四个
- D：五个涨停后低量，次日放量阴跌打到跌停、第三日低开高走直击涨停、再连四个
- F：连续十天下跌的最后一跌、老辣，次日（6.12）第二次预报，当天涨停连拉五个
- G：低量、次日涨停确认；目标为 D 后首板（5.11）**19.90×2=39.80 元**，7.1 第三次预报、午后 14:29 封死
> 庄家「老辣」且善「示弱」：吸筹时弱如笨牛吃草、拉升后逢四五个涨停就跌停示弱；辣起来野马飞奔，**33 天 17 个涨停**。
**擒拿涨停三大诀窍**：
1. **低量柱+确认柱**：低量在谷底/凹底，次日量柱高于它即确认阶段底、介入风险小但难抓涨停
2. **低量柱+倍量柱**：底部与底气结合，次日出现倍量才是底气标志（C、F 柱）
3. **缩倍的低量柱**：夯底与拉升呼应，休克清洗浮筹，次日开盘半小时量能有效放大即有涨停可能（D、G 柱）
> 口诀：低量柱，不起眼，阶段最低是底底；低量+确认柱，底部确认要珍惜；低量+倍量柱，底气十足最可期；缩倍低量看次日，放量启动抓涨停。
### 【现代化升级】
1. **「百日低量」参数化**：`vol < ref(LLV(vol, 100), 1)`，2026 年沿用。**但注册制次新股不适用**（上市不满 100 日的票没有「百日」基准），需在 `liangxue_genes.py` 加 `listed_days >= 120` 过滤。
2. **低量柱判定必须市值分桶**：`vol_rank_in_bucket <= 0.10`（桶内 bottom 10%），不用绝对量能。
3. **「低量+倍量」是 2026 年回测中双重验证最强的组合**：
   - 极致缩量（量比≤0.3）次日 +3.07%
   - 真倍量柱（is_real=true）效力 > 基准
   - 组合形态=「探底+确认」完整链路
   - **反向警告**：低量+**假**倍量（is_real=false）= 算法在测试抛压，不是真启动。
4. **「任何阶段低量柱后一定上升」的严谨化**：原书是经验之谈，2026 年必须改成可证伪命题——**「桶内 bottom 10% 低量柱后 5 日收盘价中位数变化率 > 0 的占比」**，用 5555 只 × 10 年日线数据在 12 月考场里跑。

# 第三单元 · 六个层面（第13–18讲）
## 第13讲 黄金柱：牛股与黑马的温度计
### 【核心定义】
黄金柱=以将军柱为基础、以临界点为契机、以缩量柱为陪衬升华而成的「经典量柱」，不仅独当一面、而且**顶天立地**。凡将军柱后三天均为缩量柱且具「价涨量缩」特征者即是。
**三个要素**：
| 要素 | 内容 |
|------|------|
| 一 | 当天必须是某阶段将军柱（高量/倍量/平量/梯量等重要量柱形成的栋梁之柱） |
| 二 | 后三天必须是缩量柱、价涨量缩，股价上倾、量柱下倾，**喇叭口越大越好** |
| 三 | 后三天收盘价没跌穿该柱最低价，最好连阳缩量、收盘价保持在该柱最高价上方 |
### 【市场机理】
黄金柱为什么能让股票「牛」——三层递进：
1. **双重价值是乘法不是加法**：在倍量/高量/平量/梯量柱基础上叠加缩量柱功能，1×1 的乘法放大效果
2. **缩量=惜售=涨价前兆**：股价涨了却没人卖，想买买不到的货色必然涨价
3. **是主力精心组织的行情发端**：主力先稳筹码测浮筹，第三天仍无量放出，确认洗筹震仓见效，才放心展开新一轮拉升
**三个级别**：
| 级别 | 特征 | 介入 |
|------|------|------|
| 过顶黄金柱 | 超过左侧平行峰顶、具突破性攻击性 | 位置合适、可直接介入 |
| 托底黄金柱 | 托起左侧下滑峰底、截断下滑、具护盘自救性 | 次日确认后介入更稳妥 |
| 中继黄金柱 | 补充前一黄金柱力量、继承升势、具接力加速性 | **最安全、最有利润** |
> 中茵股份（ST天华）核心发现：涨停最多处都从中继黄金柱开始。
**中兵光电（600435，图3-13-1，2009.1.14 预报）**：**9.65 元**启动→4.7 涨 **22.90 元**（除权价），不到三个月三倍。15 根重要量柱：
| 柱 | 性质 | 说明 |
|----|------|------|
| A | 倍量/试探，是将军非黄金 | 长期下跌底部首次倍量 |
| B | 倍量/接力黄金 | 后连续三缩量、价升量未超 B |
| C | 倍量 | 仅一日价升量缩即被 D 接力 |
| D | 倍量/过顶黄金 | 腾空突破 BC 峰顶 |
| E | 黄金柱 | 后三日价升量缩、标准双重黄金柱 |
| F | 黄金柱/假阴柱 | 高开低走、收盘高于前日最高，持强示弱 |
| G | 接力黄金（欠佳） | 与 F 距离远、力不从心 |
| H | 高量柱 | 不能升华黄金柱 |
| I | 独立黄金柱 | 独木不成林、数月调整 |
| N、O | 双重黄金柱 | 接力拉升 |
### 【实战要点】
**测幅功能**：主力从建仓到洗盘补货、没有成倍拉升就没利润，故**合格黄金柱至少有双倍拉升幅度**。
- 中兵 E（1.15）最高 **11.14 元**×2=22.28，实际 4.7 最高 22.90（精准）
- 中茵第②级底线 D 最高 **3.98 元**→第④级应 7.96，实际 M 收 8.06（误差 0.01%）
- 第③级 J 最高 **6.76 元**→第⑥级应 13.52
**两个限定**：①位置限定=处于黄金梯上的黄金柱；②性质限定=必须过顶黄金柱。
| 级别 | 介入 | 安全性 |
|------|------|--------|
| 过顶 | 直接介入 | ★★★ |
| 托底 | 次日确认 | ★★ |
| 中继 | 第一缩量柱 | ★★★★ |
> 口诀：黄金柱，三要素，将军缩量喇叭口；三天价升量缩缩，不破最低价才够；过顶冲锋最凶猛，托底护盘要等证；中继接力最安全，第一缩量是买点；双倍测幅要记清，二测四来三测六。
### 【现代化升级】
1. **术语**：第 4 版「黄金柱」与「将军柱」「元帅柱」同归「**王牌柱**」大类。
2. **测幅公式必须分层使用（重要）**：
   - **适用**：大盘蓝筹/趋势股/黄金梯结构完好的票 → 起点×2 保留
   - **砍半使用**：连板/题材股 → 起点×1.5（2025 年平均连板高度 2.3 板，比 2020 年 4.5 板腰斩，测幅公式必须同步衰减）
   - **不适用**：黄金线已被击穿的票（前提破坏）
3. **黄金柱判定的完整代码逻辑（可入 liangxue_genes.py）**：
   IF 基柱为将军柱（阳胜阴+三日不破底+三日不过顶）
      AND 后三日 close 递增 AND 后三日 vol 递减（价升量缩）
      AND 后三日收盘价均 > 基柱最低价
      AND is_real(基柱) == true
   THEN 标记为黄金柱，级别按「过顶/托底/中继」分类
4. **黄金柱+is_real=false = 假黄金柱**：对倒刷出来的「黄金柱」看似完美，实为算法诱多。这是本项目对量学最独特的贡献。

## 第14讲 黄金线：支撑与涨幅的温度计
### 【核心定义】
黄金线=「黄金支撑线」简称，既是主庄苦心经营的**攻防线**、又是步步为营的**生命线**；离开它主庄无法指挥千军万马、调遣资金，抓住黄金线=掐住主庄脉搏。
- 它是黄金柱的衍生功能、孪生兄妹。
### 【市场机理】
**量价平衡点**=黄金柱后三日最低价没有跌破的那个点位（可能是最高价、最低价、实体上端或下端），是经市场检验的买卖力量平衡点。
**取点方法**：先找黄金柱，以柱后三日最低价为指针。熟练前可用「**四分法**」：
| 取点 | 适用 | 基点 |
|------|------|------|
| ① 上引线最高位 | 后三日 K 线均高于黄金柱最高价 | 当日最高价 |
| ② 下引线最低位 | 后三日有 K 线低于黄金柱最低价 | 当日最低价 |
| ③ 实体最高价 | 后三日 K 线高于实体最高价 | 实体上端（收盘） |
| ④ 实体最低价 | 后三日有 K 线跌进实体之间 | 实体下端（开盘） |
**杉杉股份（600884，图3-14-1，2009.1.9 盘中推荐）**：A–E 五柱几乎都是高量/倍量形成的黄金柱：
| 柱 | 特征 | 画线/后市 |
|----|------|-----------|
| A | 后三量缩、K 未破 A 底 | 当日最低价取点，后四次探底在线上攀升 |
| B | 量缩价高成喇叭口 | K 底与 A 顶平行线为基点；1.9 预报当天涨停、连拉三个，至 4.10 涨 3 倍、含 10 个涨停 |
| C | K 最低与 C 持平 | 最低价画支撑，后五次触线即升 |
| D | 缩量红柱兼平量、步步高 | 开盘价取点（谨慎），平量黄金柱 |
| E | 高量、量缩但不协调 | 最低价画线，有样子无实质=次黄金柱 |
**维维股份（600300，图3-14-2，2009.4.13）攻防**：
| 柱 | 特征/操作 |
|----|-----------|
| A | 后三日不破底、B 倍量拉起=黄金柱，可盘中大胆介入 |
| B | 后三日一阳两阴、不破 B 对应 K 最高价，在该最高价画线，两次瞬间下探即拉起 |
| C | 后三日不破 C 最低、量缩，再画黄金线，步步高升 |
| D | 高量后连续四日缩量下跌；谨慎者破 D 底出货，大胆者见次日缩量一倍不必出场 |
| E | 倍量兼高量、后两日缩量小阴第三日突起，依托 E 线高抛低吸做两波段 |
- **E 柱黄金线最有价值**：以后三日对应 K 最低点画线，右侧突破①②③④四峰顶、左侧支撑⑤⑥两谷底
- 4.13 预报当天冲击涨停、收涨 **9.65%**，连拉两个涨停
### 【实战要点】
1. **先找黄金柱再画线**：后三日价升量缩、最低价不破的将军柱才能画线
2. **后三日最低价是指针**：四分法对应
3. **缺口顶补充**：跳空高开且后三日不破缺口，以缺口顶画平行线
4. **画线后观察**：每次触线是否反弹、力度是否减弱；有效跌破则降仓/止损
**升幅计算两种**：
- **以线测线（级别升幅）**：第一级到第三级一般 **1.382 倍**
  - A 线 **3.43 元**×1.382=4.74，实际 C 线最高 4.92
  - C 线 **4.47 元**×1.382=6.17，实际 E 线 6.37
- **以柱测柱（目标价位）**：
  - E 柱最高 **5.76 元**×2=11.52，5.5 实际最高 13.63（高 0.33）
  - F 柱最高 **6.65 元**×2=13.30
> 口诀：黄金线，生命线，主力防守不撤点；后三不破定量价，最高最低画线看；实体上下分清楚，缺口顶上补平行；以线测线一三八，以柱测柱目标价；线上震荡可持股，线下破位要撤离。
### 【现代化升级】
1. **黄金线自动画法（可编码）**：
   黄金线 = 黄金柱后三日中的最低价
   补充：若后三日最低价均 > 黄金柱最高价 → 用黄金柱最高价
        若后三日有 K 线跌破黄金柱最低价 → 下移至实际最低价
2. **「线上持有、线下撤离」的现代化验证**：黄金线的本质是「多空力量平衡点」，这条在 2026 年依然成立（市场机制层面）；但**主力=算法集群**，黄金线更多是「程序化止损线」，被扫破的概率上升——建议加「收盘价站稳而非盘中触线」的确认条件。
3. **1.382 / 2 倍升幅分层**：同第13讲，大盘趋势股保留，连板/题材股砍半。

## 第15讲 黄金梯：涨势与涨幅的温度计
### 【核心定义】
黄金梯=依托黄金柱支撑、踏着黄金线节律，一级一级上台阶、逐步升级登高的阶梯。
**三个特征**：
| 特征 | 内容 |
|------|------|
| ① 至少三根黄金柱支撑 | 低于三根难做好 |
| ② 黄金线不被有效击穿 | 收盘价低于黄金线的 K 线不能连续三天以上 |
| ③ 每道黄金线左侧最好有峰顶支撑 | 形成一级高一级、间隔逐步加大的明显台阶 |
### 【市场机理】
**画线三步法**：①找各阶段将军柱（倍/高/平/梯量）箭头标记；②在将军柱中找黄金柱、画黄金线；③在黄金柱下方画竖线成「[」形。
**浪潮软件（600756，图3-15-1，2009.4.7 预报）——递增阶梯**：
- 7 根重要量柱，第 1、2、3、5 是倍量柱
- 七阶梯「**前密后疏、前紧后松、间隔逐步加大**」=递增阶梯
- 验证：最后柱价涨量缩次日涨停，4.7 当天涨停连拉 **6 个**；最高 **8.93 元**×2=17.86，4.20 实际摸到 17.88（精准）
**长力股份（600507，图3-15-2，2009.3.26 介入）——双重黄金柱+阴招洗盘**：
- 7 根重要量柱成 7 级、前紧后松
- 第1、2日 A、B 倍量，3.26（B）介入后连调两天、未破倍量柱三分之二、量能三分之一递减（洗盘）
- 第4日价涨量增冲过倍量最高成第二倍量柱
- 第5、6日重演洗盘、量缩小；第7日小涨量明显缩=黄金柱，七天两根黄金柱=**双重黄金柱**
- 第8日再巨阴洗盘但量更小；第9日突然涨停（启动）
- 第10日高开六个点、涨到八个点回调——实为高开低走**假阴线**
- 验证：4.14 公布，**4.20 元**→ **10.44 元**、含 **4 个涨停**，达第一目标 8.40（4.20×2，实际高 0.09）
**三种梯形**：
| 结构 | 特征 | 判断/操作 |
|------|------|-----------|
| 前紧后松（递增） | 间隔逐步加大 | 基础扎实、后期瞠目，可跟做几个来回 |
| 前松后紧（递减） | 前期猛冲、后期捉襟见肘 | 涨幅落后大盘，及时换掉 |
| 前后紊乱 | 梯级无章法 | 庄家无实力，不宜跟随 |
> 看梯形如看庄稼：初期有好苗子、后期定有好收成。
### 【实战要点】
1. **数黄金柱**：完整梯至少三根，两根可观察但不稳健
2. **看黄金线**：不能被连续三天收盘价击穿
3. **看台阶节奏**：间隔加大（前紧后松）=主升在即；缩小=动能衰竭；混乱=撤退换手
4. **看左侧峰顶**：每道线左侧最好有峰顶支撑
**测幅**：黄金梯上过顶黄金柱具双倍测幅——二测四、三测六、四测八；前提是梯结构完好。
| 动作 | 位置 |
|------|------|
| 介入 | 第一缩量柱、或黄金线附近首次回踩不破 |
| 持有 | 价在黄金线上方 |
| 止损/减仓 | 连续三天破线、或阶梯紊乱 |
| 加仓 | 新黄金柱确认且过左峰顶 |
> 口诀：黄金梯，三根柱，一级一级上台阶；线破三日要离场，峰顶支撑更牢靠；前紧后松大主升，前松后紧赶紧跑；二测四来三测六，过顶双倍才精准。
### 【现代化升级】
1. **「至少三根黄金柱」的自动化判定**：N 根黄金柱在时间序列上呈递增排列（后一根的基柱时间 > 前一根），且每根黄金线逐级抬高——`golden_line[i+1] > golden_line[i]`。
2. **「线破三日」的验证窗口**：连续三天收盘价 < 黄金线 = 有效击穿。2026 年可加严为「**收盘价 + 成交量同确认**」——收盘破线且当日放量（量比>1.5）才是真破线；缩量破线多为假破（打劫洗盘）。
3. **台阶式测幅在连板时代的衰减**：浪潮软件式 6 连板在 2025 年平均连板高度 2.3 板的环境下已属稀有，「二测四、三测六」的台阶测幅只适用于大盘趋势股，题材股必须按 1.5 倍衰减使用。
4. **黄金梯结构完好性的参数化**：三级台阶的斜率差异 `slope[i+1] > slope[i] * 0.8`（递增而非递减）。

## 第16讲 黄金仓：跌幅与升幅的温度计
### 【核心定义】
黄金仓=庄家的「持仓基本仓位和拉升基地」，藏在**打压最惨烈（连续大阴）、起伏最悚人、防守最严密（不破黄金线）、成交最密集**的台阶深处。
**三个要素**：
| 要素 | 内容 |
|------|------|
| ① 有效位置 | 位于黄金梯 **3–5 级单数台阶** |
| ② 有效支点 | 左侧有峰顶、右侧有黄金柱，峰顶至少一个、两个更好 |
| ③ 有效杠杆 | 黄金柱与左侧峰顶共同支撑黄金线=仓底，仓底**绝不击穿** |
### 【市场机理】
**三个功用**：①低价抢夺筹码；②震松上方阻力；③测试拉升空间。
**巢东股份（600318）建仓三步**：
- 2008.1.17 高 **16.18 元**→11.4 低 **2.61 元**（庄家被砸得最惨）
- 11.5 新主力进场：第一天倍量结束试探、第二天十字星、第三天低开低走捡货，三天完成建仓
- 随后 10 天从 2.61 拉到 4.90、近翻番；然后按 **0.382** 位置（4.90 价位）把 6.77 附近筹码震下，完成震仓增仓
**图3-16-1（2009.4.15 推荐）**：
- A–H 八柱，A、C、E、G、H 为倍量柱，B、D、E、F 为高量柱，A、B、C、F、H 是黄金柱，七级台阶
- 第二台阶 13 根阴线（7 根中长阴）、第四台阶末连四阴跌 20%，第五台阶与第四台阶构成「金字塔」=**黄金仓 B 仓**
- 验证：4.15 当日 **7.50 元**涨 1.45%，一个半小时后逆市涨停、收 8.09；7.3 前已到 8.96（离 10.76 差 1.80）；第三黄金仓（4.15 最低 7.12 为底）目标升至 **14.24 元**
**升幅三级**：
| 主庄 | 标准 | 升幅 |
|------|------|------|
| 弱主庄 | 无标准黄金柱 | 仓底×**1.382** |
| 强主庄 | 一根黄金柱 | 仓底×**1.618** |
| 牛主庄 | 几根黄金柱 | 仓底×**2** |
- 巢东 A 仓底 **4.00 元**×2=8.00、B 仓底 **5.38 元**×2=10.76
**金言（必背）**：
> 「牛市的打压，往往是建仓的机会；熊市的拉升，往往是出货的良机；逼近黄金线的打压，往往是介入的机会；远离黄金线的拉升，往往是出货的良机。」
### 【实战要点】
1. **找连续大阴、成交密集的台阶**：打压最狠、却不破黄金线处=仓底
2. **看单数台阶**：3–5 级单数台阶最易建仓
3. **看左侧峰顶**：峰顶+黄金柱共撑仓底
4. **仓底不破**：一旦击穿仓底=建仓失败
5. **按主庄强弱测幅**：弱 1.382、强 1.618、牛 2
6. **牛熊辩证**：牛市打压=建仓、熊市拉升=出货
> 口诀：黄金仓，藏得深，大阴砸底不破线；三级五级单数位，峰顶黄金撑仓底；弱主一三八，强主一六一，牛主仓底翻一番；牛市打压是机会，熊市拉升是出货。
### 【现代化升级】
1. **「庄家建仓」的现代化改写**：2026 年「庄家建仓」被拆解为「机构底仓+量化高频增减仓」的复合行为——黄金仓的形态识别仍然有效，但**建仓主体更分散**、时间更长。
2. **升幅三级分层的现代化**：1.382/1.618/2 的倍数本质是「主庄实力分级」，2026 年可改为「**is_real 真量柱占台阶量柱总数的比例**」作为主庄实力新指标——比例越高，升幅倍数越高。
3. **「牛市打压=建仓、熊市拉升=出货」的牛熊辩证依然成立**，但「牛熊」的判定在量化时代更难——大盘趋势与个股走势脱钩（量化中性策略使然），个股黄金仓的判定要独立于大盘。

## 第17讲 黄金劫：智慧与谋略的温度计
### 【核心定义】
黄金劫又称「打劫」，借围棋术语。主力「**先做一个笼子、然后请君入瓮**」，以黄金线为轴、围绕黄金柱狂拉狂跌、制造恐慌、揽入对手筹码。本质=**做坑**（挖坑、假摔，诱使交出筹码）。
**三个特点**：
| 特点 | 内容 |
|------|------|
| ① 稳固的行为中枢 | 以黄金线为轴，打穿第一道还有第二道支撑 |
| ② 足够的行为空间 | 先拉后打，拉升越高、打压越低 |
| ③ 可靠的行为约束 | 无大量出逃迹象，打压时量柱几乎不动（无量下跌=筹码锁定） |
### 【市场机理】
**哈高科（600095，图3-17-1，2009.4.13–8.2 共 3 个多月）**：
- A 点黄金柱（最低价画线），第四日大跌、线上止跌
- C 处连续四个跌停、无量下坠破 A 线
- D 点跌停开盘后上行；10 日后 E 点再四大跌直到 B（两次 50% 跌幅）
- B 点平量黄金柱，后 9 日横盘、第 10 日拉升连拉四个涨停、重返 A 线上达 F，**60% 涨幅**
**银谷与金坑**：
- **银谷**：2007.10.11 跌到 10.29、横盘到 11.28、拉升至 2008.1.2，巨大凹坑装银子
- **金坑**：突破凹口后的小打压、凹陷比银谷小，下蹲动作；一箭三雕（洗盘、试盘、吸筹）
- 2.4 推荐（金坑将成），随后连拉六天、两个涨停，**6.80→9.50 元**，六天涨 **39.70%**
**银基发展（000511，2007.12.26）**：
- 10.15 跌到 10.26、三波横盘 **44 天**无量
- 12.26 拉升近三倍量、次日涨 **7.79%** 冲出凹口平衡线，成 **46 天**银谷
- 后做三个金坑（一个比一个深、四次下穿平衡线），最后连拉六天、两个涨停
**凹口淘金六法则**：
| 法则 | 内容 |
|------|------|
| ① 凹口突然凹陷 | 往往比大盘提前凹陷（银基提前 1 天、哈高科提前 5 天） |
| ② 凹陷首日凶狠 | 打压越狠越像黄金劫 |
| ③ 凹陷部分量少 | 无量下跌=筹码锁定、诱空 |
| ④ 银谷/金坑右侧逐步放量 | 甚至巨量天量，主力回补 |
| ⑤ 凹口平衡线附近必有中阳/大阳 | 突破平衡线是确认信号 |
| ⑥ 银谷要大、金坑要小 | 金坑底应高于银谷，否则变银谷甚至「粪坑」 |
> **识别打劫 vs 出货的关键**：跌时量小=打劫（无量诱空），跌时量大=出货（放量真逃）。
### 【实战要点】
1. **以黄金线为轴看坑**：挖坑不破中枢、无量下跌才是打劫；破线放量则是出货
2. **银谷要大、金坑要小**：金坑底高于银谷才正常
3. **平衡线是关键**：突破凹口平衡线、出现中大阳=黄金劫结束、新升势开始
4. **右侧放量确认**：坑右侧逐步放量甚至天量=主力回补
5. **跌时看量**：缩量跌=洗盘可持/可买，放量跌=出货要跑
6. **提前于大盘凹陷**：比大盘先跌的票往往是主力主动打劫
> 口诀：黄金劫，做坑忙，先拉后打骗筹码；无量下跌是打劫，放量下跌是出货；银谷要大金坑小，平衡线上中大阳；右侧放量跟进去，黄金线轴是中枢。
### 【现代化升级】
1. **「跌时量小=打劫」被 2026 年回测强化验证**：
   - 缩量阴跌 ≠ 主动洗盘，**也可能是被动基金赎回**引发的流动性踩踏（2025 年 ETF 赎回潮案例）
   - **补丁**：缩量下跌要分「量比 < 0.5 + 换手率桶内分位 < 30% + 连续 2-3 日短柱」（真打劫）vs「被动赎回」（ETF 份额缩减）
2. **「右侧放量确认」的真伪判定**：2026 年放量可能是算法对倒，必须 `is_real == true` 才确认「主力回补」。
3. **凹口淘金六法则的参数化**：
   - 法则③（凹陷量少）：`vol凹陷 / MA(vol, 20) < 0.5`
   - 法则④（右侧放量）：`vol右侧 / vol左侧 > 1.5` 且 is_real=true
   - 法则⑤（平衡线中大阳）：`close > 平衡线 * 1.02`（2% 突破确认）
   - 法则⑥（银谷>金坑）：`min(金坑) > min(银谷)`

## 第18讲 黄金道：节律与节奏的温度计
### 【核心定义】
「道」=路径、规律。黄金道=由**天线、地线、人线**三条同方向斜线组成的三维通道，是黄金梯的升华与结晶，也是量学理论的最高境界。
**三大发明**：
| 发明 | 内容 |
|------|------|
| ① 三线组织通道 | 天线观顶、地线察底、人线识人气 |
| ② 以日子命名通道 | 以具体交易日的高低点命名，保证万人画出来的通道一致 |
| ③ 人线命名选点 | 在天地线之间选与地线趋向一致的三个最低点连线 |
### 【市场机理】
**四九通道（上证指数，图3-18-1，2009.7.10）**：
- **地线**：2008.12.31（A 点）起，五次抗跌、三次触底预报到个位数；A 与 3.3（B 点）连线
- **天线**：2009.2.16（C 点）起，八次抗涨、六次触顶预报；过 C 画与地线平行
- **人线**：4.9（B1 点）起，四次抗跌、三次预报；3.26（A1）、4.9（B1）、3.31 最低三点连线
**东方宾馆（000524，图3-18-2，2008.3.12）**：
- 地线：2.1（A）、2.26（B）连线
- 天线：2.5（C 点）起、与地线平行，至少吻合三个高点
- 人线：最低量柱处、过三个趋势点
- 验证：最高只到 **9.71 元**、一分不差
**通道三种**：
| 通道 | 操作 |
|------|------|
| 上升通道 | 触天线卖、破地线买 |
| 下降通道 | 上轨卖、下轨买 |
| 双重通道 | 综合运用 |
**案例**：
- **兴化股份（002109，2007.10.30–2008.3.7）**：触天线卖、破地线买；王子「治慌病、不保证卖最高但保证卖得值」
- **万科A（000002）**：2007.11.1 高 **40.78 元**→2008.3.5 低 **20.78 元**，下降通道
- **运盛实业（600767）**：双重通道，AB 段下降、CD 段上升，E 点出货
### 【实战要点】
1. **先画地线再画天线**：以两个最低点连地线、过最高点画平行线为天线，人线取与地线同向的三个最低点
2. **用具体交易日命名**：保证通道可复现、不主观
3. **触天线卖、破地线买**：上升通道高抛低吸；下降通道反向
4. **双重通道分段看**：一段下降、一段上升，分别操作
5. **通道是节律不是预测**：它给出节奏规律，不保证卖在最高、但保证卖得值
> 口诀：黄金道，三维通，天线地线和人线；天线观顶地察底，人线识得人气走；触到天线考虑卖，破了地线考虑买；道者律也循律为，独立不改周行殆。
### 【现代化升级】
1. **「万人画出来的通道一致」的现代化**：原书用「具体交易日高低点」保证一致性，2026 年用「**明确算法**」保证——
   地线 = 两个最低点连线（用具体日期的最低价）
   天线 = 过最近最高点作地线的平行线
   人线 = 与地线同向、天地线之间三个最低点连线
2. **通道破位的量价双确认**：破地线要加 `量比 > 1.5` 才算真破（原书只用价格），缩量破线多为洗盘。
3. **通道是节律不是预测**——这句是原书的哲学根基，2026 年依然成立，但要补充：**算法时代的通道节律更快、更碎**，同一只票可能在 3-5 日内走完原书 10-20 日的通道循环。
